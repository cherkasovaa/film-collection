# FilmCollection

![Static Badge](https://img.shields.io/badge/status-done-green)

"Film Collection" is a small movie catalog application using mock data. The goal is to get hands-on experience with core Angular concepts: components, routing, directives, pipes, and signals.

## Technology Stack

- Angular 21+
- TypeScript
- SCSS

## Getting Started

### Cloning the repository

To start working on the project, clone the repository to your local machine.

Repository: https://github.com/cherkasovaa/film-collection

```bash
git clone https://github.com/cherkasovaa/film-collection.git
```

After cloning, navigate to the project directory:

```bash
cd film-collection
```

### Installing dependencies

To start working on the project, install all dependencies:

```bash
npm install
```

### Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

### Building

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.
